# 🔍 سياسة جودة القراءات الميدانية — ما يُرفع وما يُرفض ومن المسؤول

> العقد بين مراقب الجودة (`LabAnomalyDetector`) ومشغل المختبر.
> ADR-0015. القراءة هنا = قراءة جهاز خام قبل التحويل إلى صف نتائج.

## 🎯 المبدأ

**كل قراءة تُفحص قبل أن تصبح نتيجة.** خمس طبقات مستقلة تنتج ثقة
كلية، والقرار الآلي اليوم يعتمد الطبقتين الصلبين (الحدود والضوابط)
والطبقات الإحصائية تُضيّق التحييد مع تراكم تاريخ الجهاز.

## 📊 مستويات الحكم والقرار

| الشدة | الشرط الغالب | القرار | المسؤول |
| :--- | :--- | :--- | :--- |
| `NORMAL` | ثقة < 0.45 | ✅ رفع تلقائي للبوابة | النظام |
| `SUSPICIOUS` | ثقة 0.45–0.70 | ⚠️ رفع مع مراجعة بشرية موثقة | مشغل + مشرف |
| `ANOMALOUS` | ثقة ≥ 0.70 | ❌ لا رفع — إعادة قياس | النظام (يمنع) |
| `CRITICAL` | خرق فيزيائي | 🚨 لا رفع إطلاقاً + فحص جهاز | النظام (يمنع) |

**قاعدة مطلقة**: قراءة `should_reject=True` لا تُحوَّل إلى صف نتائج
ولا تُرفع للبوابة حتى لو طلب المشغل — إعادة القياس هي الطريق الوحيد.

## 🧪 الطبقات الخمس

| # | الطبقة | المتحكم | المفعّلة |
| :--- | :--- | :--- | :--- |
| 1 | حدود فيزيائية مطلقة | `PHYSICAL_LIMITS` — نسبة FRET [0,10]، ic50_um (0,1000]، σ [0,5]، ضوابط [0,1]، حرارة [0,60] | دائماً ⇒ CRITICAL |
| 2 | نطاق الضوابط + Z' | القراءة بين الضابطين؛ Z' يُحتسب ويُعرض (رفض صفيحة عند Z'<0.5 بشري اليوم) | دائماً |
| 3 | Z-score تاريخي | ±3 ⇒ شذوذ؛ ±2 ⇒ تحفظ | ≥ 20 قراءة تاريخية |
| 4 | IsolationForest | نقطة < −0.5 ⇒ نمط ضوضاء | ≥ 20 قراءة تاريخية |
| 5 | انجراف زمني | آخر 10 قراءات تنحرف > 2σ (ddof=1) عن العشرين قبلها | ≥ 30 قراءة تاريخية |

**الصدق الإحصائي**: تحت الحد الأدنى للتدريب، الطبقات 3–5 محايدة
معلنة (Z=0، نقطة=0) — لا تمثيل بالعمل.

## 📝 المسار بعد القبول

```
قراءة NORMAL/SUSPICIOUS (بمراجعة)
  → reading_to_payload(reading, smiles=خريطة الصفيحة, ic50_um=ملاءمة المنحنى)
  → POST /batches/{id}/results على البوابة المرجعية
  → استطلاع HttpLimsLab (العقد الصارم يرفض أي صف متخالف)
  → MeasurementIngestor (يرفض simulated — الفيزياء وحدها تُبلَع)
  → الذاكرة الدائمة — UNVALIDATED حتى ترقية بشرية موثقة
```

## 🚨 التصعيد

| الحدث | الإجراء |
| :--- | :--- |
| 3 قراءات `CRITICAL` متتالية | أوقف الجلسة؛ فحص جهاز ومعايرة قبل الاستئناف |
| Z' < 0.5 في صفيحة | لا تُقبل قراءات الصفيحة — قرار مشرف موثق |
| انجراف زمني مكتشف | إعادة معايرة بمعايير جديدة قبل المتابعة |

## 🔄 مراجعة السياسة

- الحدود الرقمية أعلاه **جاءت من البروتوكول لا من الميدان** —
  أول يوم قياس حقيقي يعيد معايرتها بقرار موثق.
- أي تعديل في الحدود أو العتبات: ADR موثق + تحديث
  `tests/test_anomaly_detector.py` + إعادة قياس Recall/FPR المعلنين.

## ⚖️ المسؤوليات

| الدور | المسؤولية |
| :--- | :--- |
| النظام | فحص كل قراءة، منع رفع CRITICAL/ANOMALOUS، عرض Z' دائماً |
| مشغل المختبر | المعايرة، الضوابط، عدم تجاوز حد الساعة، إعادة القياس عند الرفض |
| المشرف العلمي | مراجعة SUSPICIOUS، قرار رفض الصفيحة، توثيق كل استثناء |
| مدير المختبر | مراجعة السياسة ربع سنوياً، اعتماد تعديل الحدود |
