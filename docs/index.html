🤖 نموذج الفعالية المعتمد (v0.12 · الذراع D)

R² عشوائي0.468
R² هيكلي0.508 ± 0.090 — يتفوق على المرتكز في كل بذرة (5 بذور Scaffold)
MAE هيكلي0.559 (وحدة log)
عدم اليقينتباين الأشجار — إشارة نسبية غير معايَرة تجريبياً
⚠️ نتائج سلبية منشورة كما هي: الوصف الفيزيوكيميائي لم يفُع (R² 0.472)، وHistGradientBoosting خسر (0.429)، والهدف الخمسي لم يتحقق عند n=900 — سقف التمثيل ≈ 0.51 والرافعة الحقيقية تنويع البيانات.

البدء السريع

جرّبها في 60 ثانية

ثلاثة أوامر تفصلك عن API كامل بتوثيق تفاعلي — أو شغّل الحاوية بمنفذين.

pharma-sdl — bash
# 1) التثبيت
pip install -r requirements.txt -r requirements-dev.txt

# 2) بوابة الـ API مع توثيق تفاعلي → /docs
uvicorn pharma_sdl.api.app:create_app --factory --port 8000

# 3) نداء فرز حي (وضع العرض — 24 جزيئاً جاهزين)
curl -s -X POST localhost:8000/api/v1/screening/runs \
  -H 'Content-Type: application/json' \
  -d '{"target_id": "7VH8_A", "top_n": 5}'
# → 202 {"job_id": "..."}
# ثم: استعلام النتيجة والتقرير العربي —
curl -s "localhost:8000/api/v1/screening/runs/<job_id>/report?lang=ar"

# أو بالحاويات: API على :8000 + لوحة تفاعلية على :8501
# أضف --profile pg لتشغيل PostgreSQL حي
docker compose up --build

⚠️ ما الذي لا تفعله هذه المنصة؟

  • تعليمية لا سريرية — تدريب على منهجية الاكتشاف، لا توصية علاجية ولا بديل عن تجارب مخبرية.
  • نموذج الفعالية — بيانات فحص واحد (Mpro) وميزات ثنائية الأبعاد فقط، ولا يُستخدم لقرارات خارج هذا النطاق.
  • الطبقة البنيوية — Boltz-2 يتطلب GPU ومفتاح المستخدم؛ باقي المنصة تعمل بلا شبكة إطلاقاً.
  • النداءات الحية (PubChem · CPIC · RxNorm · Ersilia) موسومة integration وتفشل بتدهور صادق موثق — لا أرقام مختلقة.
