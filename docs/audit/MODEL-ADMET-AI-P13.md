# تقرير دمج ADMET-AI — P13: مركز ADMET من نموذجين إلى 41 نقطة نهاية

> **السؤال المحوري:** هل يمكن توسيع قمع ADMET من «قواعد + نموذجان حيّان
> عبر خادم Ersilia» إلى **تنبؤ ML محلي شامل** دون شبكة ودون GPU ودون
> التضحية بنزاهة العرض التي بنيناها في P5–P12؟ — الجواب بالقياس الحي
> أدناه: نعم، عبر ADMET-AI v2 (هارفارد، رخصة MIT) وأثرَي نموذج خارج
> التوزيع يُنشران كما هما.

- **التاريخ:** 2026-11-04 · **زمن التنفيذ:** ~ساعة (تثبيت + تحقق + دمج)
- **المرجعية:** [ADMET-AI v2](https://github.com/swansonk14/admet_ai)
  — مجموعة من 5 طيّات لنموذجَين متعددَي المهام (Chemprop) مُدرَّبَين على
  بيانات Therapeutics Data Commons؛ النماذج مضمّنة في الحزمة (~13MB) —
  **لا تحميل عند أول استخدام ولا GPU**: الاستدلال CPU كافٍ.
- **خطوة التحقق (كما تقتضي docs/INTEGRATION-ROADMAP.md):** عقد المخرجات
  مقروء من كود الحزمة (`admet_model.py` + `constants.py` + `admet.csv`)
  ثم **قياس حي** على لوحة أدوية مرجعية قبل أي سطر عرض في الواجهة.
- **إعادة الإنتاج:**
  ```
  pip install torch --index-url https://download.pytorch.org/whl/cpu
  pip install admet-ai
  python3 scripts/run_admet_ai_p13.py   # يعمل دون شبكة
  ```
  ← يولّد `docs/audit/model-admet-ai-p13-results.json`

## 4) قراءة التصميم صادقاً — ماذا يضيف P13 وماذا لا يضيف

1. **قيمة القمع**: من نموذجين (hERG + ذوبانية) إلى 41 نقطة تغطي الامتصاص
   والاستقلاب والتوزّع والتصفية والسمية والمستقبلات النووية ولوحة Tox21 —
   في نفس التبويب وبنفس عقود العرض الصادق (قيمة + وحدة + مئين + حكم إرشادي
   موثّق العتبات).
2. **لا يمس فجوة P12**: هذه نقاط نهاية ADMET لا فعالية Mpro — تقرير P12
   وثّق ذلك حرفياً («P13 يوسّع قيمة القمع — لا يمس الفجوة»). الرافعة
   الحقيقية على الفجوة تمثيل أقوى تُقيَّم على بروتوكول `evaluate_tdc_p12.py`.
3. **حدود معلنة**: أحاديد قصوى على الجزيئات الشاذة (PPBR سالب/فوق 100) —
   لذلك كل قيمة تُعرض مع مئين DrugBank: المئين للسياق لا للحكم، والنماذج
   بحثية بحدود تعميم معروفة (إخلاء المسؤولية ثابت في التبويب).
4. **عتبات موحّدة لا مبتدعة**: عتبات hERG التعليمية (0.1/0.3) موحّدة مع
   عميل Ersilia — قرار تصميمي مُختبَر (`test_herg_thresholds_consistent_with_ersilia_client`).
5. **لا أحكام مصطنعة على الانحدار**: 8 من مهام الانحدار بلا حكم نصي —
   القيمة + الوحدة + المئين هي العرض الصادق؛ الحكم يُحفظ للرائدة الموثّقة
   العتبات (hERG، AMES/DILI/ClinTox/سرطنة/جلد، الامتصاص، BBB، الذوبانية).

## 5) الهندسة — نفس عقود المشروع حرفياً

- **نمط `ersilia_client`**: فشل الاستيراد/الاستدلال → قائمة فارغة + تلميح
  تثبيت، لا استثناءات للواجهة، نجاح جزئي مقبول، تسجيل تحذيري صادق (`logger.warning`)
  بتفاصيل الاستثناء بدل الابتلاع الصامت.
- **تحميل كسول بأثر واحد** مع فصل علمي «التوفر» (استيراد ممكن) و«النموذج
  المحمّل» — خلل حالة اكتُشف أثناء التحقق (`is_available` كان يقلب جوابه
  بعد النداء الأول لأنه كان يقرأ حالة النموذج) وأُصلح وقبلُه اختبار.
- **الحزمة اختيارية**: `[admet]` extra في pyproject — سلسلة CI لا تدفع
  ثمن torch؛ اختبارات العقود تعمل بالحقن الوهمي بلا torch، والاختبار الحي
  يتخطى نفسه في CI (`pytest.importorskip`).
- **ملاحظة بيئة موثّقة**: rdkit في بيئة القياس 2026.03.6 كما حلّتها سلسلة
  admet-ai (‏`cuik_molmaker` امتداد مترجم مرتبط ببناء rdkit محدد — محاولة
  فرض 2026.9.1 كسرت الاستيراد ورُفضت)؛ تثبيت المشروع الأساسي يبقى مثبّتاً
  على 2026.9.1 في pyproject، والحزمة الاختيارية تحلّ توافقها بنفسها.
