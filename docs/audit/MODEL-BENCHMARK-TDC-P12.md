# تقرير القياس الخارجي الرسمي — P12: المختبر السابع على TDC (خطة التطوير §3، P12)

> **السؤال المحوري:** أين يقف خط أنابيبنا الفعلي عندما يقيسه مرجع **لا نملكه**
> بمقياس **لا نحسبه**؟ — أول قياس خارجي رسمي في تاريخ المشروع: مهمتا انحدار
> من المجموعة المرجعية ADMET Group في Therapeutics Data Commons، بتقسيمها
> الرسمي المثبّت، وبذورها الرسمية [1..5]، والنتيجة كما تحسبها دالة
> التقييم الرسمية `group.evaluate_many` — لا حسبة يدوية واحدة.

- **التاريخ:** 2026-11-04 · **زمن التنفيذ:** ~9 دقائق (4 تشغيلات مستقلة)
- **المرجعية:** TDC `admet_group` — مهمتا انحدار قياسيتان بمقياس MAE وتقسيم Scaffold:
  - `Lipophilicity_AstraZeneca` — 4,200 جزيء (اختبار رسمي 840)
  - `Solubility_AqSolDB` — 9,982 جزيء (اختبار رسمي 1,997)
- **ما يُقاس بالضبط:** خط أنابيب **v0.12.0 المعتمد** (بصمة Morgan بالتكرارات
  2048bit r=2 + RandomForest 300 شجرة، `max_features=0.3`) بوصفه فئة خطوط
  انحدار SMILES→قيمة — **وليس نموذج Mpro الفعالية نفسه** (لا مهمة pIC50-Mpro
  في TDC؛ انظر §4). ذراع تشخيصية ثانية (`max_features='sqrt'`) لفصل أثر
  الإعداد المعتمد عن سقف التمثيل.
- **إعادة الإنتاج:**
  ```
  pip install PyTDC --no-deps && pip install 'setuptools<81'
  python3 scripts/evaluate_tdc_p12.py        # يعمل دون شبكة من النسخة المجمدة
  ```
  ← يولّد `docs/audit/model-tdc-p12-results.json`

## 3) قراءة الفجوة صادقاً — لماذا نحن حيث نحن؟

1. **فئة التمثيل قبل المُقدِّر:** كل المدخلات فوقنا تستخدم إما شبكات عصبية
   مُدرّبة على المهمة (Chemprop/GCN/CMPNN) أو نماذج مدربة مسبقاً على ملايين
   الجزيئات (MiniMol) أو اختيار نموذج (DeepMol/MapLight). بصمة Morgan 2048bit
   مع RF خط أساس قوي وصادق، لكنه خط أساس — والفجوة +0.25…+0.29 هي **سعر
   فئة التمثيل**، وقد قِست الآن بدل أن تُخمَّن.
2. **أين نفوز داخل فئتنا:** على Solubility نتقدم على خط أساس البصمات المنشور
   الوحيد في اللوحة (Morgan+MLP: 1.203) بفارق **0.172 MAE** — بصمة التكرارات +
   mf=0.3 أقوى من تركيبة البصمات المنشورة تلك. وعلى المهمتين معاً كان
   المعتمد أفضل من sqrt — قرارات P11 صمدت خارج مجالها.
3. **حدود يجب قولها كما هي:** على Lipophilicity نتأخر عن كل المدخلات
   المنشورة. لا نطوّل القصة: هذا هو موقع فئة خطوطنا اليوم على مرجع خارجي،
   ونشره هو بالضبط ما تعنيه ثقافة «كل ادعاء يُقاس ويُنشر».
4. **نزاهة التنفيذ:** جزيئا اختبار واحدَين في Solubility فشل تحليل SMILES
   وعُوِّض تنبؤه بمتوسط التدريب (موثّق لكل بذرة في الـJSON) — صفر استبعاد
   في Lipophilicity. النسخة المجمدة من التقسيم الرسمي ملتزمة في
   `data/external/admet_group/` مع SHA256 لكل ملف (`MANIFEST.json`) —
   القياس يعيد إنتاجه **دون شبكة**.

## 4) توثيق الفجوة بين قياسنا الداخلي والمرجع الخارجي (معيار القبول)

| البعد | قياسنا الداخلي (P0/P11) | المرجع الخارجي (هذا التقرير) | الفجوة وسببها |
|---|---|---|---|
| المهمة | pIC50 فعالية Mpro (ChEMBL4523582، 900 جزيء) | امتصاص/ذوبانية (ADMET) — **لا مهمة pIC50-Mpro في TDC** | فجوة تعريفية موثّقة: ما قِس خارجياً هو **فئة الخط** لا النموذج الموضوعي نفسه |
| التقسيم | Scaffold بذور 0–4 (تنفيذنا) + Random 42 | Scaffold رسمي من TDC (اختبار مثبّت + بذور 1–5 لـ train/valid) | نفس الفلسفة، تنفيذ TDC الرسمي — نلعب بقواعدهم حرفياً |
| المقياس | R²/MAE/RMSE + Bootstrap CI 1000× | MAE فقط عبر `evaluate_many` (متوسط ± σ) | أضفنا R² اختباري للسياق فقط — الحكم بالرقم الرسمي |
| النتيجة | R² هيكلي 0.509 (فوق خط 1-NN بـ0.101) | MAE 1.031 (Sol، مرتبة 16/18) / 0.709 (Lipo، تحت اللوحة) | الداخل يقيس **تقدمنا** عن مرتكزنا؛ الخارج يقيس **موقعنا** بين المنشور — والرقمان لا يتناقضان |

## 5) إعادة الإنتاج

```bash
pip install PyTDC --no-deps && pip install 'setuptools<81'
python3 scripts/evaluate_tdc_p12.py                          # المهمتان × الذراعان
python3 scripts/evaluate_tdc_p12.py --tasks solubility_aqsoldb --arms adopted
```

- البيانات الرسمية مجمدة: `data/external/admet_group/{task}/{train_val,test}.csv`
  + `MANIFEST.json` (SHA256) — التشغيل يقرأها بلا شبكة («Found local copy»).
- البروتوكول من مصدر TDC حرفياً: اختبار Scaffold مثبّت 20%، وtrain/valid
  بـ`create_scaffold_split` (0.875/0.125) لكل بذرة من [1..5].
- بيئة القياس المسجلة في الـJSON: Python 3.12.16 · PyTDC 1.0.0 · numpy 2.2.6
  · scikit-learn 1.5.2 · RDKit 2026.09.1 — نفس بيئة تدقيق المشروع.
- مصادر اللوحات (الوصول 2026-11-04):
  [Solubility](https://tdcommons.ai/benchmark/admet_group/06aqsol) ·
  [Lipophilicity](https://tdcommons.ai/benchmark/admet_group/05lipo) ·
  [نظرة عامة](https://tdcommons.ai/benchmark/admet_group/overview) — أرقام
  المدخلات منقولة حرفياً إلى `leaderboard_reference` في الـJSON.

## 6) ماذا بعد (مرتبط بخطة التطوير)

الفجوة الخارجية المقاسة (+0.25…+0.29 عن الأفضل) تعيد ترتيب أولويات الربع:
- **P13 (ADMET-AI):** توسّع نقاط النهاية من 2 إلى ~43 — لا يمس هذه الفجوة
  لكنه يوسّع قيمة القمع؛ أولوية كما هي في الخطة.
- **الرافعة الحقيقية على هذه الفجوة** (معلّقة على ربع البنية/التوليد): تمثيل
  مُدرّب مسبقاً أو GNN خفيف خلف علم مُعلن — تُقيَّم على هذا البروتوكول نفسه
  (`evaluate_tdc_p12.py`) فلا حاجة لإعادة بناء المرجعية.
- المهمتان مجمدتان ولوحتهما الرسمية مرجع ثابت لأي ترقية تمثيل قادمة.
