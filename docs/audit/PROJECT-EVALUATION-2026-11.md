### الأمان — مسح الأنماط الخطيرة (نظيف)
- لا `eval` / `exec` / `pickle.load` / `shell=True` / `os.system` / `yaml.load`
  غير الآمن في أي ملف بايثون.
- لا استيفاء نصوص في SQL (لا حقن قواعد بيانات).
- لا أسرار أو مفاتيح مكتوبة في الشجرة (لا `ghp_` / `sk-` / `AKIA` / مفاتيح
  مضمّنة).
- كل استدعاءات الشبكة (PubChem · CPIC · RxNav · Ersilia · ADMETlab · JapanFold)
  محكومة بـ `timeout` صريح — فُحصت 6 مواضع شُكّ بها وكلها مغطاة داخل استدعاءات
  متعددة الأسطر.
- مدخلات خارجية مُرمَّزة إلزامياً (`quote(..., safe="")`) في مسارات URL.
- مبدأ التدهور الصادق مطبَّق: غياب خدمة = `StoreUnavailableError` (503)
  موثق، لا رقم مختلَق ولا انهيار صامت.
