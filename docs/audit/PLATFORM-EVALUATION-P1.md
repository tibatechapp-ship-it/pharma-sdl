## 3. ما الذي لم يُعالج الآن — بقرار معلن لا إهمال

- **PostgreSQL/Celery/Redis كخدمات قيد التشغيل:** لا تُشغَّل هنا بلا بنية حقيقية؛ بدلها يُسلَّم **طريق الترقية كاملاً**: مخزن مهام SQLite دائم (نفس واجهة ADR-0005، الترقية محلية بلا تغيير العقود) + تصدير/استيراد JSONL للتجارب + `deploy/postgres/schema.sql` جاهز (JSONB) + ADR يحدد متى تُفعَّل الخدمات. بلا كود غير مُختبر ادّعاؤه داعماً.
- **تدوير مفتاح GitHub:** المفتاح المكشوف سابقاً في المحادثة **ما زال بحاجة إلى تدوير من مالك الحساب** — لا يمكن للمنصة أن تفعل ذلك عنه.

## 4. قرار الانتقال إلى P2

بعد معالجة 1–8 أعلاه واختبارها، تنتقل المنصة إلى **P2**: مصادقة وRBAC + وضع عرض عام محدود + مهام دائمة + جناح redocking بلورية مرجعية + طريق PostgreSQL الموثق — بلا أي ترقية آلية لحالة الاعتماد، وبلا ادعاء غير مُختبر.
