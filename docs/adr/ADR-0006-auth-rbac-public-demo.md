# ADR-0006 — المصادقة والأدوار ووضع العرض العام

**الحالة:** مقبول · **التاريخ:** 2026-11-01 · **السياق:** تقييم ما قبل P2 (docs/audit/PLATFORM-EVALUATION-P1.md، إشكاليات #5 و#6)

## السياق

بوابة الاعتماد العلمي (P1) تعلن أن الترقية «بشرية موثقة» — لكن الـAPI لم يكن يعرف
من هو البشر: أي طرف يستطيع إطلاق فرز أو رفع نتيجة إلى `EXPERIMENTALLY_SUPPORTED`
بلا هوية ولا أثر. وكأول نشر عام، لا حد معدل ولا سقوف: vina على نفقة المشغّل.

## القرار

**1) مفاتيح API + ثلاثة أدوار صارمة** (`pharma_sdl/api/auth.py`):

| الدور | يفعل |
| --- | --- |
| `viewer` | كل القراءة: أهداف، محركات، نتائج، تقارير، تجارب، بطاقات اعتماد |
| `scientist` | + إطلاق الفرز والفحوص المخبرية |
| `admin` | + ترقية/تخفيض حالة الاعتماد — **حصراً** |

- المفاتيح من البيئة حصراً: `PHARMA_SDL_API_KEYS="id:key:role,..."` — تُجزَّأ
  sha256 عند التحميل، لا سر خام في الذاكرة أو الاستجابات؛ إدخال مشوه يُسقط
  الإقلاع (المصادقة النصفية أخطر من غيابها).
- الوضع المفتوح (بلا مفاتيح): التطوير المحلي كما هو — كل طلب admin **مع إعلان
  صادق** في `/health` (`auth_mode: "open"`).
- نقاط مفتوحة دوماً حصراً: `/`، `/api/v1/health`، `/api/v1/version` (فحوص
  الحاويات والمراقبة — لا تكشف شيئاً).

**2) وضع العرض العام المحدود** (`pharma_sdl/api/demo.py`) — `PHARMA_SDL_DEMO_MODE=1`:

- حد معدل لكل IP (token bucket) بترويسات `X-RateLimit-*` و`Retry-After` و429 صادق.
- قفل المحركات على القائمة المسموحة (افتراضياً `simulation` حصراً) — عرض لا يشتري.
- سقوف أدنى: 25 ليغاند/طلب وtop_n ≤ 10.
- `/health` يصرّح `demo_mode: true` — لا وضع محدود خفي.

## البدائل المرفوضة

- **JWT/OAuth الآن:** بلا مستخدمين فعليين ولا واجهة حسابات — تعقيد بلا حاجة؛
  مفاتيح API كافية لفريق علمي ونقاط تكامل، والترقية لاحقاً لا تغيّر عقود المسارات.
- **إغلاق `/health` خلف المصادقة:** يكسر healthcheck الحاويات والمراقبة الخارجية
  بلا فائدة أمنية.
- **حد معدل في بروكسي عكسي فقط:** يترك النشر المباشر مكشوفاً؛ الحاجز في التطبيق
  يرافق البروكسي ولا يتوقف عليه.

## النتائج

- الترقية عبر API متاحة أخيراً — وهوية المُجيز (`actor`) حقل إلزامي في الطلب.
- النشر العام ممكن بأمر واحد: `PHARMA_SDL_DEMO_MODE=1 PHARMA_SDL_API_KEYS=... docker compose up api`.
- الحد الأقصى للصدق: `/health` يعرض وضعي المصادقة والعرض دائماً — لا انطباع أمني كاذب.
