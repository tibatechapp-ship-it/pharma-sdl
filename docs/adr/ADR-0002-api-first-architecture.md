# ADR-0002 — API-First: المكوّن قبل الواجهة

- **الحالة:** مقبول (2026-11-01)
- **السياق:** التطبيق Streamlit ينمو بمنطق مدمج داخل الواجهة؛ أي استهلاك آخر
  (دفاتر، مختبر تشغيل آلي، عملاء خارجيون) يتطلب نسخاً موازية من نفس المنطق.
- **القرار:** كل قدرة جديدة تُبنى في حزمة `pharma_sdl/` بعقد Pydantic واضح،
  وتُعرَض عبر FastAPI تحت `/api/v1` بـOpenAPI تلقائي. واجهة Streamlit تصبح
  عميلاً من عملاء الـAPI — لا حاوية للمنطق.
- **التبعات:** الاختبارات تعمل على العقود لا على الشاشات؛ الـCLI والدفاتر
  تستدعي نفس الدوال؛ إعادة تصميم الواجهة لا تلمس المنصة.
