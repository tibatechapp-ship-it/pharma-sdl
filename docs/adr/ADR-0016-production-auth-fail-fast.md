# ADR-0016: تحصين النشر — بيئة الإنتاج تفرض المصادقة والإعدادات تفشل بوضوح

**الحالة:** مقبول (2026-11-05) · **الإصدار:** v0.17.0 · **المرحلة:** P16
**السياق:** مراجعة نشر خارجية (2026-11-05) رصدت سبع ثغرات تشغيلية — أربع
منها تسمح بإطلاق نسخة على الإنترنت بحالة أضعف مما يظنه مشغّلها.

## السياق

المنصة وُلدت للتعليم والبحث المحلي: الوضع المفتوح (بلا مفاتيح API) كان
الافتراضي الصادق لغرضها. لكن نفس الافتراضي على خادم عام = منفذ إدارة
بلا حارس، ومحدّد معدل يقرأ ترويسة يتحكم فيها العميل، وذاكرة تنمو بلا سقف،
وإعدادات خاطئة تعمل بصمت. الصدق البنيوي الذي يميز المشروع يقتضي أن يكون
**الوضع المفتوح قراراً معلناً لا افتراضياً على الإنترنت**.

## القرار

1. **بوابة الإنتاج (fail-fast):** ‏`PHARMA_SDL_ENV=production` بلا مفاتيح
   API → `create_app()` يرفض الإقلاع بـRuntimeError صريح. الوضع المفتوح
   يبقى حق `development` حصراً — لا كسر توافق مع أي مستدعى قائم.
2. **نموذج الثقة بالبروكسي:** ‏`X-Forwarded-For` لا يُقرأ إلا عند
   `PHARMA_SDL_TRUST_PROXY=1` (بروكسي يعيد كتابة الترويسة). الافتراضي
   False يقرأ IP المباشر — الترويسة المزوّرة لا تصنع هويات جديدة لتجاوز
   حد المعدل.
3. **ذاكرة محدودة:** دلو الرموز ينسى الهويات التي انقضى أفق امتلائها
   الكامل (حالتها = السعة، فالنسيان لا يغيّر القرار)، وسقف صارم
   (`max_identities=10_000`) يُخلّي الأقدم نشاطاً — تحويل الهويات المزيفة
   يضغط السقف لا الذاكرة. الحد يبقى لكل عملية (لا Redis) — وثيقة الحدود
   معلنة في المصدر.
4. **إعدادات تفشل بوضوح:** قيمة غير رقمية/غير معروفة لأي متغير حرج توقف
   الإقلاع برسالة تسمّي المتغير (لا تخمين صامت)، و`validate()` يفحص
   الحدود المنطقية (المنفذ، السقوف ≥ 1، postgres بلا DSN = رفض — ADR-0008).
5. **compose صادق:** ملف التعريف `pg` يُشغّل `api-pg` موصولاً فعلياً
   (‏STORE=postgres + DSN داخلي + انتظار جاهزية postgres + فحص صحة يقر
   بـ`store_backend=postgres`) — لا مشغل يشغّل postgres ويظن التطبيق
   يستخدمه. وسم الصورة من متغير واحد بقيمة افتراضية مطابقة لـpyproject.
6. **حاوية بلا root:** مستخدم `appuser` (uid 10001) بملكية /app —
   اختراق الحاوية يصطدم بصلاحيات محدودة.
7. **CI بأقل صلاحية:** ‏`contents: read` على مستوى workflow، والكتابة
   حصراً في job الشارة المنفصل — خطوة تثبيت/اختبار مخترَقة لا تتمكن
   من الدفع إلى main.

## البدائل المرفوضة

- **إلزام المفاتيح دائماً:** يقتصر العرض التعليمي المحلي (`streamlit run`
  + API للمطور الجديد) — ضد غرض المشروع الصريح «بلا مفاتيح للتجربة».
- **Redis لحد المعدل:** طبقة تشغيل جديدة لمشروع عرضه الافتراضي
  عملية واحدة — يوثَّق الحد لكل عملية بدل ادعاء مراكزي كاذب.
- **ملف .env مُلتزم:** مفاتيح في الملفات = ما تحريمه SECURITY.md حرفياً.

## العواقب

- إيجابية: فشل مبكر برسائل تسمّي المتغير؛ لا وضع مفتوح غير مقصود؛
  ذاكرة محدودة؛ عقود النشر مُختبَرة (compose/Dockerfile/workflow).
- تكلفة: مشغّل نسخة إنتاجية عليه ضبط `PHARMA_SDL_API_KEYS` قبل الإقلاع —
  وهذا هو الهدف.
- متبقٍ معلن: حد المعدل لكل عملية؛ لا مخزن مراكز؛ لا migrations
  تلقائية (مسار PostgreSQL عقداً موثقاً في ADR-0007/0008).
