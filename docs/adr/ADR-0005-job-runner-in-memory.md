# ADR-0005 — طابور مهام داخل الذاكرة في v0.2.0

- **الحالة:** مقبول (2026-11-01)
- **السياق:** جولات الفرز الحالية ثوانٍ–دقائق والمستخدم العلمي واحد؛ مزاوجة
  Celery/Redis الآن تكلفة تشغيل بلا حاجة فعلية.
- **القرار:** `jobs/runner.py` طابور خيوط داخلي بحالة في الذاكرة وTTL ساعة.
  عقد الاستهلاك (معرّف مهمة + حالة + نتيجة) مستقر، فالترقية إلى وسيط رسائل
  محصورة في هذا الملف وحده.
- **التبعات:** إعادة تشغيل الخدمة تفقد المهام غير المنتهية (مقبول الآن وموثّق
  في /docs)؛ عند تعدد المستخدمين أو طول المهام (Boltz-2 على GPU) تُفعَّل
  الخلفية الدائمة.
