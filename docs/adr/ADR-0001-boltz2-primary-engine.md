# ADR-0001 — Boltz-2 محرك التقارب الأساسي

- **الحالة:** مقبول (2026-11-01)
- **السياق:** الخطة الاستراتيجية v1.1 طلبت محرك تقارب سريعاً ومفتوحاً تجارياً.
  AlphaFold 3 استُبعد: أوزانه غير تجارية (CC BY-NC) رغم تحول كوده إلى Apache-2.0
  في 2026-06. Boltz-2 بترخيص MIT يتنبأ بالتقارب مباشرة (أسرع بمراتب من FEP).
- **القرار:** Boltz-2 هو محرك التقارب المرجعي في المنصة، يُستهلك عبر بوابة
  `PHARMA_SDL_BOLTZ2_ENDPOINT` (عقد JSON موثّق) أو حزمة محلية عند توفّر GPU.
- **التبعات:** `engines/boltz2.py` يعلن عدم توفره بصدق حتى تهيئة البوابة — لا
  أرقام مختلقة. الفرز لا يتغير (عقد `DockingEngine` موحّد).
