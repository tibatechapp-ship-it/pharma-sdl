# التحليل التنافسي — Ryko وPharma SDL في خريطة الذكاء الدوائي

**لقطة 2026-11 · مرافقة لإصدار v0.19.0 (P19)** — تُحدَّث مع كل إصدار رئيسي،
وكل ادعاء هنا مصدره معلن أو مقيد بمعيار قابل للفحص.

## 1. الخريطة — من نتنافس معهم فعلاً؟

| الفئة | المنافسون | ماذا يفعلون |
|---|---|---|
| وكلاء كيمياء LLM | **ChemCrow** (Bran et al., Nat. Mach. Intell. 2024)؛ **Coscientist** (Boiko et al., Nature 2023)؛ **Google AI co-scientist** (Gemini 2.0، 2025) | توليد مسارات اصطناع، تخطيط تجارب، تكامل أدوات عبر LLM |
| تعلم آلي كيميائي مفتوح | **DeepChem**؛ **TorchDrug** | مكتبات نماذج للخصائص والألكترونية |
| تنبؤ ADMET | **ADMETlab 3.0** (Research 2024)؛ **ADMET-AI** (Stanford)؛ **pkCSM**؛ **ADMET Predictor** (Simulations Plus — تجاري) | بطاقات خصائص وسمية من البنية |
| نماذج لغة طبية | **BioMedLM** (2.7B)؛ **Med-PaLM** (Google)؛ OpenBioLLM وما جراها | سؤال وجواب طبي وتوليد نص |
| منصات خط اكتشاف | المنصات التجارية المغلقة (CADD suites، عقارية) | خط كامل بسحابة واشتراك |

## 2. أين نحن — بالمقاييس المعلنة فقط

| البعد | Pharma SDL + Ryko | أفضل منافس في الفئة |
|---|---|---|
| خط اكتشاف كامل مفتوح المصدر | ✓ تنقية←فرز←فعالية←ربط←ADMET←قرار←تقرير | DeepChem/TorchDrug: مكتبات بلا خط؛ ChemCrow: أدوات بلا خط مكتمل |
| عقل علمي بإيصالات قابلة للتحقق | ✓ 43 عملية حتمية، بصمة SHA-256، تحقق دون اتصال | لا يمنح أي منافس إيصالاً قابلاً لإعادة الحساب — أرقام LLM غير قابلة للتحقق بطبيعتها |
| عربي أولاً | ✓ الواجهة والتقارير والخطأ ثنائية اللغة | صفر دعم عربي معلن لدى الجميع |
| بلا مفاتيح وبلا شبكة | ✓ يعمل محلياً من الصندوق | ChemCrow/Coscientist: تعتمد GPT-4؛ Med-PaLM: سحابة Google |
| اختبارات ملزمة | ✓ 876 ناجحاً على CI | DeepChem قوي؛ وكلاء LLM يتأرجحون بمعايير تقييم متنازع عليها |
| تنبؤ ML للفعالية | R² هيكلي 0.508 معلن | ADMET-AI/ADMETlab 3.0 أقوى في breadth (41 مهمة لدينا مقابل 100+ لديهم) |
| واجهة تفاعلية | Streamlit تعليمي + API-First | منصات تجارية أرقى بصرياً |
| قاعدة معرفة الأمراض | بذرة بايزية فقط (P21 قادمة) | Med-PaLM/BioMedLM أوسع معرفياً بكثير |

## 3. نقاط ضعف المنافسين — وما نستفيد منها

| المنافس | الضعف المعلن | فرصتنا |
|---|---|---|
| وكلاء LLM (ChemCrow/Coscientist/co-scientist) | الهلوسة الرقمية بلا إيصال؛ اعتماد مفاتيح وAPI؛ صعوبة التحقق المستقل | **إيصال Ryko يجعل كل رقم مُحاسَباً** — نموذج مساعد لاحقاً (P22) خلف بواباتنا يجمع قوته بصدقنا |
| ADMETlab 3.0 / ADMET-AI | تنبؤ سطح كيميائي فقط — لا يجيب الجرعة والانحلال والاحتمال | Ryko U4/U5 يملأ فجوة ما بعد ADMET (صيدلانيات وفارما) |
| Med-PaLM / BioMedLM | إنجليزي حصراً؛ أرقام بلا مصدر؛ سحابة إلزامية | العربية أولاً + حساب حتمي معلن المصدر |
| منصات تجارية | مغلقة، اشتراك، بلا تدقيق مستقل | مفتوح المصدر كاملاً + CI علني قابل للتدقيق |
| DeepChem/TorchDrug | مكتبات خام — ليست منصة جاهزة للمستخدم النهائي | نحن منصة خط كامل بعقل جاهز |

## 4. نقاط ضعفنا الصادقة — وخطة العلاج

| الضعف | الأثر | العلاج المعلن |
|---|---|---|
| breadth ADMET: 41 مهمة محلية مقابل 100+ لدى ADMET-AI | تغطية سموم أضيق | توسيع تدريجي عبر جسورها (P13/ADR-0017 معلن) |
| قاعدة CYP/DDD محدودة (14/8 إدخالات) | لا تغطية تفاعلات شاملة | توسيع بمصادر معلنة في كل إصدار — بلا اكتمال زائف |
| لا عقل لغوي مساعد بعد | التفسير السردي يدوي | P22: نموذج محلي خلف بوابات الإيصال — يشرح لا يخترع |
| لا خريطة أمراض كاملة | المرحلة الثانية بذرة | P21: قاعدة معرفة مُدقَّقة (ICD-11 subsets) |
| لا DOI ولا إشارة أكاديمية بعد | الاعتماد الأكاديمي صفر | هدف STRATEGY-2026: ≥3 إشارات في منهج أو ورقة |

## 5. التمييز الحاسم (نقطة القوة التي لا يملكها أحد)

**«كل رقم من Ryko يحمل معادلة ومصدراً وبصمة قابلة لإعادة الحساب — بالعربية أولاً — دون شبكة.»**

هذا المزيج الثلاثي (تحقق دون اتصال + عربية أولاً + صفر مفاتيح) غير موجود لدى أي
منافس في الجدول أعلاه، وهو امتداد طبيعي لفلسفة المنصة المعلنة: كل رقم مصدره
معلن، وتدهوره صادق. نبني عليها بدل مطاردة نقاط قوة الآخرين في ملعبهم (حجم
النماذج، breadth السحابة) — هناك لا نستطيع المنافسة، وأمامنا هنا نملك الميزة.
