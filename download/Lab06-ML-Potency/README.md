# Lab06 — التنبؤ بالفعالية بالتعلم الآلي (ML Potency)

دفتر منفَّذ كاملاً (21 خلية، 3 رسوم) يدرّب نموذج RandomForest على قياسات
IC50 **الحقيقية** لـ SARS-CoV-2 Mpro من ChEMBL (900 جزيء) ويتنبأ بفعالية
أدوية معتمدة مع فترة ثقة من تباين الأشجار.

## التشغيل
```bash
pip install -r requirements.txt
jupyter lab Lab06_ML_Potency.ipynb
```

## الملفات
- `Lab06_ML_Potency.ipynb` — الدفتر المنفَّذ (مخرجات + رسوم مضمّنة)
- `data/mpro_sample.csv` — 900 جزيء (smiles, pchembl_value, mol_chembl_id)
- `requirements.txt` — الاعتماديات

## أبرز النتائج (من التنفيذ المرفق)
- R² ≈ 0.44 ، RMSE ≈ 0.78 على 180 جزيء اختبار لم يرها النموذج
- نيرماتريلڤير: تنبؤ 7.21 (القياس الأدبي ≈ 7.7 — داخل فترة الثقة)
- الأسبرين المزخرف: عدم يقين أوسع بكثير — النموذج "يعترف بجهله"
