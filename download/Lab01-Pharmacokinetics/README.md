دفتر Jupyter جاهز للتشغيل — أول مختبر من سلسلة **«الكتاب الحي»**، مرتبط مباشرة بـ **الفصل 2** من كتاب *علم الأدوية: من الجذور التاريخية إلى التقنيات المتقدمة الحديثة*.

## 📦 محتويات المجلد

| الملف | الوصف |
|---|---|
| `Lab01_Pharmacokinetics.ipynb` | الدفتر الكامل — **منفّذ مسبقاً** بكل الرسوم الخمسة (شغّله من جديد لتجربة بارامتراتك) |
| `fonts/Tajawal-Regular.ttf` + `Bold` | الخط العربي للرسوم (يُحمَّل تلقائياً من الدفتر) |
| `requirements.txt` | المكتبات المطلوبة |

## 🚀 التشغيل في 30 ثانية

```bash
pip install -r requirements.txt
jupyter notebook Lab01_Pharmacokinetics.ipynb
# ثم: Cell → Run All
```

أو ارفعه على **Google Colab** مباشرة (`File → Upload Notebook`) — كل شيء يعمل، والرسوم ستستخدم الرموز العلمية الإنجليزية تلقائياً إن لم يتوفر الخط العربي.

## 🧭 ماذا ستبني في هذا المختبر؟

| الجزء | المفهوم النظري (الفصل 2) | الكود |
|---|---|---|
| 1 | نموذج الحجرة الواحدة IV | `iv_bolus()` — C(t) = C₀·e^(−kt) |
| 2 | الإعطاء الفموي وباتيمان | `oral_bateman()` + قياس Cmax/Tmax/AUC |
| 3 | التراكم والحالة المستقرة | `repeated()` — مبدأ التراكب |
| 4 | النافذة العلاجية والقرار | `clinical_report()` → حكم: آمن/ضبط/سمّي |
| 5 | حالة 2026 (Orforglipron/Enlicitide) | مقارنة فموي يومي × حقن أسبوعي |

+ **3 تمارين محلولة + تحدي الجرعة التحميلية** — كلها مُتحقَّق منها عددياً ضد الصيغ التحليلية.
